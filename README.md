## English Overview

### What Problem This Repo Solves

Most faceless YouTube creators stall at two points:

1. **Blank-page pacing**: Writing a 7–10 minute voiceover script without clear beat transitions causes audience drop-off in the first 40 seconds.
2. **Saturated niche lists**: Generic "top 50 faceless niches" blog posts recycle the same crowded categories and attach invented RPM numbers or unverified search-volume claims.

This repository packages the open Markdown blueprints and verified low-competition dataset extracted directly from NicheCue's production data files (`data/niches.json` and `data/niches.zh.json` on [facelessyoutubeniches.com](https://facelessyoutubeniches.com/)).

### How to Use These Templates Safely (Originality Rules)

Every outline in this repo and on [NicheCue](https://facelessyoutubeniches.com/) follows strict originality guardrails so your channel avoids YouTube's reused-content flags:

- **Borrow structure, never sentences**: Use the beat order (`0:00` hook -> setup -> timed evidence beats -> contrast -> recap card), then write original TTS or human voiceover copy.
- **Keep visual cadence moving**: Plan a visual change (stock clip, archival photo, labeled map, cross-section diagram, or consistent AI B-roll frame) every 8–12 seconds.
- **Cite on-screen sources**: Display source names, archive dates, or reference timestamps in lower-thirds instead of vague "experts say" filler.
- **Verify demand directly on YouTube**: Before batching 10 episodes in any lane, search 5 sample titles on YouTube to check recent upload cadence and real viewer interest.
